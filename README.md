# REDbox_Plugin

This repository contains a Unity UPM package for REDbox integration.

Package path:
- `Packages/com.redbox.unity`

Install from another Unity project:
1. Open Package Manager.
2. Choose `+` > `Add package from git URL...`
3. Use `https://github.com/jmgech/RedBox_UPMPlugin.git?path=/Packages/com.redbox.unity`

Pinned install example:
- `https://github.com/jmgech/RedBox_UPMPlugin.git?path=/Packages/com.redbox.unity#milestone-2026-03-19-plugin-rbx-v0.3-sync`

Detailed setup:
- `Packages/com.redbox.unity/Documentation~/README.md`
