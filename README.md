# REDbox_Plugin

This repository contains a Unity UPM package for REDbox integration.

Package path:
- `Packages/com.redbox.unity`

Install from another Unity project:
1. Open Package Manager.
2. Choose `+` > `Add package from disk...`
3. Select `Packages/com.redbox.unity/package.json`

Detailed setup:
- `Packages/com.redbox.unity/Documentation~/README.md`
